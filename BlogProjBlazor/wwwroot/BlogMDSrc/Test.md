# GitHub Flavored Markdown 完整示例

这是一个用于测试 AST 解析的 GFM 文档，包含所有标准特性

## 1. 标题层级

# H1 标题
## H2 标题
### H3 标题
#### H4 标题
##### H5 标题
###### H6 标题

## 2. 文本样式
---
- **粗体文本** 或 __粗体__
- *斜体文本* 或 _斜体_
- ~~删除线文本~~
- ***粗斜体*** 或 ___粗斜体___
- `内联代码`
- <sub>下标</sub> 和 <sup>上标</sup>
- <kbd>Ctrl</kbd> + <kbd>C</kbd>

## 3. 列表

### 无序列表
- 项目 1
- 项目 2
    - 嵌套项目 2.1
    - 嵌套项目 2.2
- 项目 3

### 有序列表
1. 第一项
2. 第二项
    1. 嵌套第一项
    2. 嵌套第二项
3. 第三项

### 任务列表
- [x] 已完成任务
- [ ] 未完成任务
- [ ] 子任务
    - [x] 子任务已完成
    - [ ] 子任务未完成
